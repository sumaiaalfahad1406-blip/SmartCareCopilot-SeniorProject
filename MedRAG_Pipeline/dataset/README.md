# MedRAG Dataset

This folder contains the dataset resources used in the SmartCare Copilot MedRAG pipeline.

## 1. Generated Dataset File

**`AI Data Set with Categories.csv`**

This file is not uploaded to GitHub because of its large size.

It is automatically generated by running `preprocess_ddxplus.py` using the original DDXPlus training data and metadata files.

The generated CSV is subsequently used by `training.py` to prepare patient JSON records.

## 2. Clinical Retrieval Embeddings

**`clinical_retrieval_embeddings.npy`**

This file contains the precomputed clinical embeddings used by the MedRAG retrieval system.

It is not included in the GitHub repository because of its large size.

### How to Generate the Embeddings

1. Prepare the DDXPlus dataset using `preprocess_ddxplus.py`.
2. Run `training.py` to generate the patient JSON records.
3. Use the embedding-generation functionality in `main_MedRAG.py` to convert the retrieval patient descriptions into numerical vectors using OpenAI's `text-embedding-3-large` model.
4. Save the generated embedding matrix as `clinical_retrieval_embeddings.npy` inside the `dataset` folder.

An OpenAI API key and access to the required retrieval patient records are necessary for embedding generation.

### Important Notes

- The embedding file must be generated or provided locally before running the MedRAG retrieval pipeline.
- Once generated, the embeddings can be reused without regenerating them for every consultation.
- Regenerating embeddings requires OpenAI API requests.

## 4. Reproducibility

The generated CSV and embedding files are excluded from GitHub to reduce repository size. They can be recreated using the provided preprocessing and embedding-generation code, the required DDXPlus source files, and the appropriate configuration.
