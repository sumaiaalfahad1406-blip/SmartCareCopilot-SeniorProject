# MedRAG Dataset

This folder contains the DDXPlus resources used in the SmartCare Copilot MedRAG pipeline.

## Generated Dataset Files

**AI Data Set with Categories.csv**

Generated by `preprocess_ddxplus.py` using the original DDXPlus training data and metadata files. It is excluded from GitHub because of its large size.

**clinical_retrieval_embeddings.npy**

Contains the precomputed clinical embeddings used for retrieval. It is excluded from GitHub because of its large size.

The file can be recreated using the embedding-generation functionality in `main_MedRAG.py`, after preparing the retrieval patient records.

## Patient JSON Files (`df/`)

The `df` directory contains processed patient records organized into three dataset splits:

```text
df/
├── train/
│   └── patients/
├── validate/
│   └── patients/
└── test/
    └── patients/
```

- **Train:** Used to construct the clinical retrieval database.
- **Validate:** Used to evaluate the pipeline during development.
- **Test:** Used for final diagnosis accuracy evaluation.

The patient JSON files are generated from the corresponding DDXPlus data using the project's data preparation scripts.

## Reproducing the Dataset

1. Obtain the original DDXPlus dataset files.
2. Run `preprocess_ddxplus.py` to generate `AI Data Set with Categories.csv`.
3. Run the appropriate data preparation scripts to create the patient JSON records for each split.
4. Generate the clinical retrieval embeddings using `main_MedRAG.py`.
5. Place the generated files in their expected dataset locations before running the MedRAG pipeline.

## Note

Large generated files are not included in this repository. They must be recreated locally using the provided scripts and required source data.
